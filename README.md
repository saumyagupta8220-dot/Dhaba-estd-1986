# 🪔 Dhaba Estd. 1986

A vibrant and rustic restaurant website inspired by the traditional Punjabi dhaba experience.

The website brings together authentic Punjabi food, highway-dhaba aesthetics, restaurant outlets, testimonials, ordering options, and table booking in a modern responsive interface.

## ✨ Features

- 🏠 Attractive hero section with background video
- 🍛 Punjabi dhaba-inspired visual design
- 📱 Fully responsive layout
- 🥘 Food and restaurant sections
- ⭐ Customer testimonials
- 📍 Multiple dhaba outlets
- 🪑 Table booking section
- 🛵 Online ordering section
- 📰 Media mentions section
- 🎬 Smooth animations using GSAP
- 🎨 Custom colors and typography
- ⚡ Fast React + Vite setup

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- GSAP
- JavaScript
- HTML5
- CSS3
